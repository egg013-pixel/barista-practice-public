# 독립 공유용 검증

원본 기준: 3abf50b. 원본 저장소·Vercel 프로젝트·기존 공유 링크는 변경하지 않습니다.

정적 내보내기만 게시합니다. Google Sheets와 평가 서버 API, 자동 전송 및 온라인 복구 전송이 없습니다. 내장 평가와 브라우저 음성, 3D 시뮬레이터, 로컬 기록·기간 조회·선택 삭제·CSV를 사용합니다.

원본과 별도의 `barista-public-*` 저장 키를 사용합니다. 학생 기록과 API 키는 배포 파일에 포함하지 않습니다.

검증 완료: 내장 평가·음성 안내·시뮬레이터·저장 복구 단위 테스트 40개, 브라우저 테스트 16개 통과.

GitHub Pages 경로(`/barista-practice-public/`)로 생성된 정적 배포 파일을 로컬 HTTP 서버에서 실제 Chromium으로 열어, 시작 3D·시험장 3D·내장 피드백·단계 전환·교사용 기록 링크·직접 새로고침·기간·CSV·삭제·원본 저장 키 보존·모바일 가로 넘침 없음·서버 API 요청 없음까지 추가 검증했습니다.

GitHub 연결이 새 저장소 생성 및 Pages 관리 요청을 Resource not accessible by integration으로 거절했습니다. 새 공개 저장소 생성·연결 및 Pages 활성화 전에는 예정 공유 주소가 동작하지 않습니다.

최종 게시 완료: 새 공개 저장소가 생성된 것을 확인한 뒤 main(39d7fac)과 gh-pages(5a0147a)를 업로드했습니다. Pages가 활성화됐으며 공유 주소와 admin/ 모두 HTTP 200입니다. 공개 사이트에서 31개 정적 파일을 내려받아 로컬 배포본과 SHA-256이 모두 일치함을 확인했습니다. /api/sheets는 404이며 교사용 페이지에 Sheets 연결 안내/재전송 버튼이 없습니다.

기존 저장소 main은 3abf50b로 유지됐으며 기존 Vercel 주소도 HTTP 200입니다. 기존 private 저장소에는 복사본 백업을 위한 share-no-sheets 브랜치만 추가했습니다.

## 2026-11-04 비저장 공유용 전환

이름·수험번호 입력, 개인 식별 세션 필드, 저장된 이어하기·교사용 기록·CSV 및 브라우저 기록 저장 코드를 제거했습니다. 결과·단계·3D 동작은 현재 화면 메모리에만 유지하고 새로고침/종료 시 복구하지 않습니다. 이전 공유용 저장 키 3개만 삭제하는 마이그레이션을 모든 앱 페이지에 적용합니다. 다른 앱의 키를 읽거나 지우지 않습니다.

개인정보처리방침과 시작 화면·마이크 안내를 실제 동작에 맞게 수정했습니다. 브라우저 음성 및 호스팅의 외부 처리 가능성은 별도로 남겼습니다. 자기소개는 가상의 정보로 연습하며 실명과 입력 번호를 대조하지 않습니다.

내장 평가·음성·이전 저장 키 삭제/차단 복구 단위 테스트 41개 통과. 브라우저 검증은 실제 정적 내보내기를 별도 로컬 HTTP 서버에서 제공합니다. 소프트웨어 WebGL 최초 로딩은 20초, 11단계 전체 흐름은 120초 예산으로 일반 버튼·평가 검증과 구분합니다. 배포용 빌드에서 식별 정보 없이 전체 글 대본 연습, 새로고침 초기화, 저장 API 차단, 이전 키 정리와 다른 앱 보존, 마이크 미지원 입력, /admin/ 404를 확인했습니다. 3D 전체 흐름 및 모바일·데스크톱 배치는 별도 실제 브라우저 검사로 확인합니다.

최종 확인
단위 검사 41개와 브라우저 12개 고유 시나리오를 분할 실행해 확인했습니다. 브라우저 검사는 정적 빌드에서 진행했고, 소프트웨어 WebGL 최초 로딩과 전체 11단계에는 별도 시간 예산을 사용했습니다. 이번 레이아웃/전체 흐름 검사는 reduced-motion 설정으로 실행했으며 실제 하드웨어 GPU의 기본 모션 성능을 보장하는 검사는 아닙니다.

## 2026-11-05 공개 모델 음성 전환

- TTS는 Qwen3-TTS-12Hz-0.6B-CustomVoice 공식 Apache-2.0 체크포인트와 Uncle_Fu 남성 프리셋으로 생성한 한국어 안내 11개입니다. 개인 음성 복제는 하지 않았습니다. wav/원문/생성 모델 리비전/sha256을 manifest에 기록하며 빌드 때 안내문과 해시 일치를 확인합니다. 모델 자체와 학생 음성은 저장소에 포함하지 않습니다.
- STT는 WebGPU 지원 기기에서 Whisper large-v3-turbo q4, 나머지는 Whisper small q8을 전용 Worker에서 실행합니다. Transformers.js 3.8.1과 self-hosted ONNX Runtime WASM을 사용합니다. 모델 다운로드는 고정 리비전, 브라우저 CacheStorage/FS cache는 끄고 열린 페이지 메모리에서만 모델을 재사용합니다. 오디오와 텍스트를 원격 추론 서비스에 보내지 않습니다. 모델 파일 다운로드는 외부 접속 정보 처리가 있을 수 있어 방침에 반영했습니다.
- 단계 안내 자동 재생 취소, 마이크 준비/녹음/인식/취소, 30초 제한, 준비 실패·권한 거절·저장 공간 차단 시 직접 입력을 검증했습니다. 기존 Web Speech API로 자동 폴백하지 않습니다.
- 단위 40개 통과. 정적 빌드에서 음성 준비 취소·직접 입력·가짜 Worker와 실제 브라우저 MediaRecorder를 사용하는 데스크톱 3D 마이크·11단계 글 대본 및 비저장 회귀 시나리오 8개를 분할 실행해 통과했습니다.
- 실제 Whisper small ONNX CPU 모델로 생성 안내 11개를 자동 전사했습니다. 불완전했던 3번 음성을 다시 생성했으며, 전사 결과에는 수험번호/카푸치노 등의 일부 표기 차이가 있습니다. 사람의 청감 평가나 모든 발화의 인식 정확도를 보증하는 검사가 아닙니다.
- 실제 Chromium WASM 엔진에 고정 리비전의 Whisper small 파일을 로컬 미러로 제공하고, 합성 한국어 안내를 가짜 마이크 장치로 입력해 캡처→16kHz 변환→실제 모델 추론→텍스트 표시를 확인했습니다. POST 업로드가 없고 localStorage/sessionStorage가 빈 상태임을 검사했습니다. 외부 Hugging Face CORS/대용량 다운로드의 모든 학교망 환경과 실제 하드웨어 WebGPU 경로는 이 클라우드에서 확인하지 못했습니다. 준비에 실패하면 직접 입력을 사용할 수 있습니다.
- 설치 과정의 v4 런타임 파일 탐색/메타데이터 호환 문제는 v3.8.1로 고정해 해결했습니다. 실제 배포용은 기본 Hugging Face 주소를 사용하며 QA의 로컬 미러 주소를 포함하지 않습니다.
