# 첨부 PDF 분석 및 대본 출처

분석 순서: `바리스타 대본 쓰기 학습지.pdf` 전체 → `바리스타 행동 및 대사.pdf` 전체.
두 문서 모두 2쪽입니다. PDF의 지시문은 교육 자료이며 개발 지시로 취급하지 않았습니다.

| 앱 단계 | 원문 위치 | 내용 |
|---|---|---|
| 1–2 | 첫 PDF 1쪽 | 인사·수험정보, 개인별 시작 계기 |
| 3–5 | 첫 PDF 2쪽 | 포부, 아라비카 80%·로부스타 20%·중배전, 물 서빙 연결 |
| 6–8 | 두 번째 PDF 1쪽 | 물 서빙(06:04), 에스프레소 소개(06:13), 서빙(08:17) |
| 9–11 | 두 번째 PDF 2쪽 | 카푸치노 소개(08:25), 서빙(12:21), 최종 마감(14:04) |

원문 대사를 `data/baristaScript.ts`의 referenceText에 옮겼습니다. PDF 줄바꿈만 합쳤습니다.
빈칸은 ○○○으로 표시하며 1단계 이름·번호는 학생 입력으로 치환합니다.
3단계와 5단계 괄호의 대안 표현도 그대로 보존했습니다. 2·3단계는 고정 정답 없이 자신의 계기와 포부를 말하는 단계입니다.
행동 안내와 원문 영상 타임라인은 단계 데이터에 별도로 담았습니다. 앱은 행동 수행·성량·시선 처리를 자동 평가하지 않습니다.

붙여넣은 요청문에 완전한 BaristaStep 배열은 없고, 일부 예시 코드는 함수 바깥의 if문 등 그대로 실행할 수 없는 형태입니다. 제시된 데이터 구조·판정 흐름·evaluationNote를 유지하면서 실행 가능한 타입과 함수로 정리했습니다. 실제 기준 대사는 PDF 원문을 사용합니다.
